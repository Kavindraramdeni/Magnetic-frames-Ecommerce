# KRIA AI — Quick-Start Guide

Your internal AI business operations workspace for **KRIA Tech** (`https://kriatech.in`).

## Folder Structure

```text
kria-luxuary-ecom/
├── GEMINI.md                              # Core guardrails & approval rules
└── kria-ai/
    ├── README.md                          # This guide
    ├── leads.csv                          # B2B Lead Tracker (CRM)
    ├── knowledge-base/
    │   ├── business-profile.md            # Brand, location, delivery, B2B rules
    │   └── products.md                    # Verified catalog, dimensions, prices
    ├── skills/
    │   ├── growth/SKILL.md                # Prospecting, keywords, campaigns
    │   ├── website/SKILL.md               # Technical SEO, schema, backups
    │   ├── email/SKILL.md                 # Mailbox health, quote & follow-up drafts
    │   └── automation/SKILL.md            # Weekly reports & scheduled tasks
    ├── drafts/                            # Outreach & email drafts awaiting approval
    └── reports/                           # SEO audits, keyword research, summaries
```

## Example Prompts to Run

- **Growth:** *"Find 20 potential bulk buyers (wedding planners or photo studios) for our magnetic acrylic photo frames and save them to `leads.csv`."*
- **Website:** *"Run a technical SEO and schema audit on `kriatech.in` and save the report to `kria-ai/reports/`."*
- **Email:** *"Draft a B2B quote reply for 100 Classic Polaroid return gift magnets using `products.md` and save it in `kria-ai/drafts/`."*
- **Automation:** *"Generate this week's SEO keyword & article ideas report in `kria-ai/reports/`."*
